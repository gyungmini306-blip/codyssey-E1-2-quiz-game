## 요구사항 확인

| 항목 | 결과 및 근거 |
|---|---|
| 메뉴 및 종료 | 1~5 메뉴 선택, 종료 시 저장 |
| 기본 퀴즈 5개 이상 | `defaults.py`에 E1-1 세 문제, E1-2 두 문제 |
| Quiz 클래스 | question, choices, answer 속성 및 display, is_correct, to_dict 메서드 |
| QuizGame 클래스 | 메뉴, 출제, 추가, 목록, 점수, 저장/불러오기 분리 |
| 숫자 입력 처리 | 공백 제거, 빈 입력, 문자, 범위 초과 입력 후 재입력 확인 |
| 퀴즈 추가 및 목록 | 실행 검증에서 문제 1개 추가 후 6개 목록 확인 |
| 정오답 및 결과 | 6문제 중 3개 정답으로 50점 출력 확인 |
| 최고 점수 | 미플레이 안내, 최고 점수 갱신, 낮은 점수로 덮어쓰지 않음 확인 |
| UTF-8 JSON 저장 | 프로젝트 루트의 state.json 사용, 한글 저장 |
| 재실행 후 데이터 유지 | 실행 검증에서 6개 퀴즈와 50점 불러오기 확인 |
| 파일 없음 및 손상 | 기본 5개로 시작/복구, 저장 시 유효한 JSON 생성 |
| 파일 읽기·쓰기 실패 | 자동 검증에서 권한 오류 안내 및 저장 실패 반환 확인 |
| Ctrl+C·EOF | 자동 검증에서 두 예외 확인, 실제 프로세스에서 EOF 종료 확인 |
| 의미 있는 커밋 10개 이상 | 기능별 개발 커밋과 수정·문서 커밋으로 충족 |
| 브랜치 생성·병합 | feature/play 개발 및 main으로 병합한 이력 확인 |
| init/add/commit/push/checkout/clone/pull | 개발 및 GitHub 복제 실습에서 사용. [실습 기록](git-workflow.md) 참고 |
| README 필수 항목 | 개요, 주제 선정 이유, 실행 방법, 기능, 파일 구조, 데이터 설명 작성 |
